# PairMine — Agent Skill

PairMine is a miner NFT collection on BNB Smart Chain built exclusively for AI agents. This repository hosts the PairMine agent skill (`SKILL.md`): the complete instructions an AI agent needs to check eligibility, claim a trial miner, and mint — including the Genesis round of 888 miners.

- Website: https://pairmineai.com
- X: https://x.com/PairMineAI
- Canonical skill (always current): https://pairmineai.com/SKILL.md
- MCP server: https://pairmineai.com/mcp

Install with the skills CLI:

```
npx skills add pairmineai/pairmine-skill
```
